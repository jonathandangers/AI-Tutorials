Module 06

Do not let an important project live only inside a chat.

A longer conversation is not always a better one. Keep threads short and focused, and keep the state of a project somewhere you control.

Pocket card

  • New topic: new thread. Very long thread: save what you trust and start fresh.
  • Platform memory helps, but it is not your project record.
  • Keep an external project home. Use a platform project, with instructions and skills, as the working space that points to it.

A longer conversation is not always a better one.

What the context window does

The model works from the information available in the current context. As a thread gets longer, more material has to be processed. That uses more of your available usage, and very long threads can become noisier: older details or instructions may be harder to distinguish from newer ones.

When to start a new thread

Start a new thread when you change topics. For a long-running piece of work, start fresh when the existing conversation has become unwieldy.

Before you leave a thread, export what you approved to the project home: the finished output and an updated current-state document. The next thread starts from those, so nothing depends on the old conversation.

Simple rule: new topic → new thread. Very long thread → export approved state, then start fresh. Important project state → save it outside the thread.

Four layers of memory

Why the external home matters

A project home survives a long thread, gives you a clean place to restart, lets you hand the work to another model or person, and keeps the trusted outputs separate from all of the exploratory conversation that produced them.

The platform project and the external home work together. The project's instructions tell the model what the work is and where the current state lives. The home holds what you have approved. Telling the model where the folder is does not give it access: upload the current-state document and the files the task needs at the start of each thread, or connect the tool to the folder and check that it can actually read it. Starting a new thread then takes seconds.
