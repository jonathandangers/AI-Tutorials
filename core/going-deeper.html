Module 09

Useful once the basics start repeating.

Three ways to stop rebuilding the same setup by hand. Come back to these once a workflow is something you do every week.

09

Pocket card

  • Skills package instructions you use repeatedly.
  • A personal context portfolio carries how you work across tools.
  • Scheduled tasks start recurring work without you. Start with ones that report back for review.

Skills: save instructions you use repeatedly

A skill packages recurring instructions and supporting knowledge so you do not have to reconstruct the same prompt every time. This is useful for work such as meeting summaries where you repeatedly want the same structure, length, style, and areas of attention.

For cross-platform work, it can be useful to keep the canonical instructions with the rest of the project so they can be maintained and adapted for more than one model or platform.

Personal context portfolio: portable information about how you work

If you work across multiple models, you can maintain an external set of important personal or professional context: recurring preferences, roles, constraints, working style, or other information that would materially change how an assistant helps you. Project-specific instructions can tell the model when to retrieve the relevant portions.

The tradeoff is maintenance: portable context is only valuable if the important parts stay current.

Scheduled and automated tasks: let recurring work start without you

Once a workflow is stable, recurrence can become a trigger: literature surveillance, newsletter consolidation, reminders, or internal preparation. Start with automations whose output comes back to you for review rather than sending or acting externally without oversight.
